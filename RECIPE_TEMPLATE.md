# THIS IS A BASIC TEMPLATE OF HOW TO FORMAT MOST RECIPES  
if you are having trouble, check other recipes to see how they are formatted

# ABSOLUTELY NO COPY PASTING RECIPES FROM WEBSITES!!!

* I WILL CHECK EACH RECIPE ADDITION INDIVIDUALLY SO PLEASE FOLLOW THE FORMATTING RULES   
* Make sure to add everything into a folder so all the pictures and instructions(if multiple) are in the same spot


# Recipe name + picture
quick description, what it is? how many does it make? cook time? all little things like that go here

# Ingredient list
It should look something like this: 
* (measurement) salt
* (measurement) flour  
Every new ingredient gets a bulletpoint.

# Equipment list
Just like the ingredient list, every different piece of equipment(bowl, pan, pot, whisk) gets a bulletpoint. Make sure this list includes most of everything, things like measuring cups and other items that are a given when cooking are not needed here.

# Instructions
Every new instruction gets a bulletpoint, and make sure the instructions are clear, easy to read, and get to the point. If applicable, preheating the oven, prepping a dish with spray and things like that go first.

# Notes
If there are optional steps/variations to your recipe, put them here
